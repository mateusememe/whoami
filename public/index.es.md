## Proyectos

- [rinha-backend-2026-c](https://github.com/mateusememe/rinha-backend-2026-c) (1 estrellas): Detección de fraude por búsqueda vectorial para la Rinha de Backend 2026, en C11. KNN sobre 1.000.000 de vectores de referencia en memoria compartida, con SIMD ARM Neon, cuantización en punto fijo de 16 bits y 4.096 buckets espaciales. Latencia mediana cercana a 250 µs con 1 vCPU y 350 MB. Stack: C11, ARM Neon SIMD, KNN, POSIX SHM.
- [megabrain-context-protocol](https://github.com/mateusememe/megabrain-context-protocol) (3 estrellas): Material del taller de Model Context Protocol (MCP) en DevFest 2026. Construye DevBrain, un servidor MCP en Python que indica a un agente de código si una rama está lista para un pull request. Las reglas de revisión viven en el código, y el mismo servidor funciona en Claude Code, Gemini CLI, Copilot y Codex. Stack: Python, MCP, AI Agents, Cloud Run.
- [syntroph](https://github.com/mateusememe/syntroph): Toolkit y orquestador en Go que conecta herramientas de desarrollo alrededor de un núcleo hexagonal. Un bus de eventos en proceso entrega la salida de un adaptador al siguiente, un saga journal append-only registra cada paso, y la memoria de sesión queda local, con GitHub Issues o Wiki como espejo. Stack: Go, Hexagonal Architecture, Event Bus, MCP.
