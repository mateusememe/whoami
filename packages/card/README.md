# mateusememe

Business card of Mateus Mendonça Monteiro, backend software engineer, for the terminal.

```bash
npx mateusememe        # language from LANG, else English
npx mateusememe --pt   # or --en, --es
```

No dependencies. Colors follow `NO_COLOR` and turn off when the output is piped.
The data (`card.json`) is generated from the portfolio in
[mateusememe/whoami](https://github.com/mateusememe/whoami) by `npm run generate`.
